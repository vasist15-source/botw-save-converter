# BotW Save Converter

Converts a Breath of the Wild save between Wii U (Cemu) and Switch (Ryujinx), in either direction.

**Use it here: https://vasist15-source.github.io/botw-save-converter/**

Pick the save folder (the one with `option.sav` and the numbered folders `0`–`5`). The page works out
which console the save came from, converts it to the other one and gives you a `.zip` to unpack into the
other save folder. Everything runs in the page; the save is never uploaded anywhere.

It is one HTML file with no build step, so you can also download `index.html` and open it locally.

The conversion follows the same rules as BotWSaveManager 1.1.4. Keep a copy of your original save until
you have loaded the converted one in the game.

Made alongside [BOTWRecomp](https://github.com/vasist15-source/BOTWRecomp), the native Apple Silicon port
of Breath of the Wild.
