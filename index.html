Breath of the Wild save converter

Pick a whole BotW save folder. It works out which console it came from and converts it to the other one. Everything runs in this page; your save never leaves your computer.

Your save folder

The folder that holds option.sav and the numbered folders 0–5. On Cemu that is …/mlc01/usr/save/00050000/101c9400/user/80000001. Drag it here or choose it.

What changes in the file

A save is a list of game flags, each a 4-byte name hash and a 4-byte value. The Wii U stores numbers big-endian and the Switch little-endian, so every number is byte-reversed. Item and place names are text and stay exactly as they are. These are real bytes from slot 1:

OffsetWii USwitchMeaning
0x000000 00 47 1b1b 47 00 00save version
0xcc0022 a5 10 d1d1 10 a5 22hash of a pouch-item flag
0xcc0449 74 65 6d49 74 65 6d“Item”, text kept
0xcc0c5f 45 6e 655f 45 6e 65“_Ene”, text kept
  • game_data.sav, caption.sav, option.sav: every word reversed, except values of text flags (known hashes, or values starting with a known name like Item, Weap, Obj_).
  • trackblock*.sav (Hero’s Path): first word as is, second word as two 16-bit values, the rest reversed.
  • Pictures (album, Hyrule Compendium, slot thumbnails) are plain JPEGs and copied unchanged.
  • Same rules as BotWSaveManager 1.1.4, checked byte for byte against its output. Older saves are upgraded by the game when it loads them.

Where the converted save goes

Ryujinx (Switch)

Right-click the game → Open User Save Directory. Back up what is there, then unzip into it so option.sav and 0–5 sit at the top.

Cemu (Wii U)

Unzip into

mlc01/usr/save/00050000/101c9400/user/80000001

Real console

Restore with JKSV or Checkpoint on Switch, SaveMii on Wii U, using the same folder layout.

Keep a copy of your original save until you have loaded the converted one in the game.
